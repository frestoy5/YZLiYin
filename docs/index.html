核心能力

这首歌播不了？
它自己换个地方继续放

版权下架、接口 403、会员只能试听 30 秒——遇到这些情况，播放器不该弹一句「暂时无法播放」就把你晾在那。

  • 固定轮转，不死循环按 网易云 → 酷狗 → B站 的顺序去找，并记住「放坏链接的源」自动跳过。
  • 打分匹配，不是瞎猜歌名、歌手、时长三项加权打分，够及格线才切，避免换成另一首同名歌。
  • 换错了还能换回来播放页右下角标注「来自 XX」，一键「更换音频」手动搜回你想要的那一版。

邀请链接 / 深链直达

复制链接或六位密钥发给朋友，冷启动也能接住深链弹窗确认；兼容 NeriPlayer 客户端协议。

可自建服务器

默认官方服务端，也支持填自己的地址；邀请链接强制 https，断线自动重连。

房间权限可控

是否允许成员暂停、切歌、拖进度都由房主决定，成员进出时可自动暂停。

常见问题

你可能会问

?收费吗？会塞广告或会员吗？+
完全开源免费，没有广告、没有内购、没有统计上报。项目的出发点就是 README 里那句「欢迎所有喜欢开源盛世的人」。
?我的账号安全吗？数据会上传吗？+
登录凭据保存在本机（YouTube 凭据用 EncryptedSharedPreferences 加密存储并定期轮换），搜索与播放解析都在本地完成。只有「一起听」需要连接房间服务器——可以自建。
?怎么安装到手机上？+
仓库暂未挂官方 Release 包，可克隆源码后执行 ./gradlew assembleRelease 本地出包，产物在 app/build/outputs/apk/release/。最低支持 Android 8.0。欢迎关注 Releases 页获取后续正式包。
?一起听怎么和朋友连上？+
在「一起听」页用当前播放队列建房，把邀请链接或六位房间号 + 密钥发给朋友，点开即可加入；支持剪贴板一键加入，也兼容 NeriPlayer 客户端的深链协议。
?支持哪些音质？有无损吗？+
有。网易云支持标准 / 较高 / 极高 / 无损 / Hi·Res，酷狗最高 Hi-Res，B站提供 64K–192K，YouTube 提供四档自适应；设置页可按音源分别配置，播放页会显示当前实际来源。
?和 NeriPlayer 是什么关系？+
音之理音在设计上参考了开源项目 NeriPlayer（GPLv3），一起听协议与其服务端字段一一对应、可互通，YouTube 解析部分移植自其 fork。相关版权声明保留在「设置 → 关于」中。
